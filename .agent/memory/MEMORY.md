# MEMORY

## プロジェクト概要
- 夢野久作『ドグラ・マグラ』（青空文庫 No.2093）を「遊べば本当に読了したことになる」ブラウザゲーム（再読型ノベルADV＋遊べる論文＋証拠カード対審）にする趣味プロジェクト
- 目的：ホラー一辺倒でなく，精神病学的考察・作中論文（脳髄論・胎児の夢・心理遺伝論）・入れ子の執筆構造・円環構造を体験で理解させる
- 構造の正本は `analysis/sections.json`．原文は `.references/aozora/`（改変禁止）
- 決定事項と理由は `.spec/KNOWLEDGE.md`「決定事項と理由」を参照

## 学習した知識・教訓
- 計画の大きな判断は Gemini と Codex の両方に聞くと意見が割れることがある．採否と理由を KNOWLEDGE.md に残す
- Codex に作品理解の誤り（モヨ子＝六号室の少女 等）を指摘された．文学作品の人物・出来事は原文行で裏取りしてから仕様に書く
