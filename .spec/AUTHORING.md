# 章データ執筆ガイド（M2）——`src/data/chapters/Sxx.ts`

## 目的
『ドグラ・マグラ』の各区分を「遊べば本当に理解できる」場面データにする．読者は **原文の抜粋を縦書きで読み → 要旨 → 三時点の注釈 → 証拠カード → 理解課題** の順に体験する．全文は「原文全文」ボタンでいつでも読める（抜粋で全部を語る必要はない）．

## 絶対規則
1. **原文の改変・捏造禁止**．原文を引用する文字列は必ず `<q>…</q>` で囲む（要旨・カード・用語・命題・課題のどこでも）．`<q>` 内は原文と**一字一句一致**（句読点「、。」も原文のまま．「……」「——」もそのまま）．検証スクリプト `analysis/verify_scenario.py` が全 `<q>` を原文と照合する．不一致は不合格
2. 引用でない説明文（注釈者の言葉）は句読点を **「，．」** にする（原文引用の内側だけ「、。」）
3. **「作中の主張」と「現代の知見」を必ず分ける**．正木の学説・作中の医学は「作中の仮説」．現代医学の定説として書かない．**原文の語（「狂人」「キチガイ」「片輪」等，現代では差別的とされる語を含む）は，注釈・場面題・カード題・課題文でも言い換えない**（西村方針 2026-09-03：当時のオリジナルを尊重し，現代風に直して印象を変えない）．用語集の `caution` に「作中で使われる語」と短く記すのはよいが，注釈者の文で「精神病者」「患者」などに置き換えてはならない
4. 三時点を分離：`era1926`＝作中時間（大正15年10月，作中の設定・当時の制度），`era1935`＝刊行時（昭和10年，当時の読者・医学・文学状況），`modern`＝現代の知見・倫理からの注釈．`era1935` は `.spec/REFERENCES.md` の史実メモと参考文献に基づいて**積極的に書く**（「本作だけからは分からない」で済ませない．文末に（参考：鶴見 1989）のように出典略号を付ける）．史実メモにない事実は書かない．`modern` は推測で書かず，確かでないことは「〜とされる」「作中では示されない」と書く
5. 情報源（`source`）を毎場面つける：`kind` は perception（語り手の知覚）／explanation（誰かの説明）／document（作中文書）／inference（語り手・登場人物の推測）／meta（作者・巻頭歌など）．`trust` は 1〜3（3＝作中で複数の裏付けがある，1＝一人の言い分のみ）．`who` は「若林鏡太郎（法医学教授）の説明」のように具体的に
6. 事実／発言者／推測／反証をカードで分ける（M1 と同じ形式）．`src` は必ず「S03 行210–226」のように行番号を書く

## 場面（Scene）の作り方
- 1区分を **3〜6 場面**（S06・S12・S13 は 1〜3）．各場面の `blocks` は原文の連続範囲で **合計 20〜45 行**（1行＝1段落．長い段落が多い箇所は少なめに）．物語の骨格・作中文書の要点・名場面・後で効いてくる伏線を優先．場面の間で飛ばした部分は `summary` の冒頭で「（この間：…）」と短く補う
- `id` は `S03-1` のように区分 id＋連番．`title` は場面名（原文の章題があればそれを使う）
- `bg` は次から選ぶ：`dark`（暗転）／`room7`（七号室）／`corridor`（病院の廊下）／`lab`（標本室）／`ward`（解放治療場・患者たちの空間）／`street`（門付け・街頭）／`lecture`（講堂・教授室）／`paper`（作中文書の紙面）／`scroll`（絵巻物）／`newspaper`（新聞）／`letter`（手紙）／`night`（夜・海・月）．`depth` は語りの現在＝0，作中文書＝1，文書内の文書（遺言書内の手紙など）＝2
- 作中文書の冒頭場面は `blocks[0].heading` に原文の見出し（表題・副題）を配列で入れる（本文の行はそのぶん `from` を後ろへ）
- `style`：新聞は `newspaper`，手紙は `letter`，絵巻は `scroll`，それ以外は省略
- `summary`：HTML．2〜4 段落．最後の段落は `<p class="who">注釈者の言葉：…</p>` で「この場面で確かなこと／誰の言葉か／読者が疑うべき点」を書く
- `notes`：`era1926` `era1935` `modern` 各1〜3文．`roles`（物語上の役割・構造上の意味）は任意
- `event`：場面末尾で `card`（`cards` に id）／`game`（`game` に種別，未実装なら `gameNote` に要旨3〜5行．種別：saimon＝外道祭文リズム，whoismad＝誰が狂人か，exchange＝交換局（実装済，S07 のみ），totsuki＝十月十日，emaki＝絵巻照合，assistant＝助手モード，trial＝証拠対審，choice＝結末の選択）／`task`（章の最終場面．理解課題を出す）／`book`（S04 の原稿発見のみ）

## 章（Chapter）のそのほか
- `cards`：2〜5 枚．`info: true` は「作中説／現代医学／物語上の役割」型の解説カード
- `task`：4〜6 問．**正解当てではなく「誰の説明か」「支持する証拠は」「反証は」**を選ぶ形式．`fb` は解説（正誤どちらでも読める文）．`answer` は 0 始まり
- `terms`：用語・人物・文書・場所を 4〜10 件（初出の区分に置く．他区分で既出なら書かない）．`inText`＝作中での意味，`quote`＝原文の定義的一節（`<q>` 必須），`modern`＝現代からの注釈，`caution`＝注意（差別語・虚構の医学など）
- `claims`：命題台帳 2〜6 件．作中の重要な主張（「私は呉一郎である」等）を **誰が言ったか・信頼度・支持証拠・反証** と行番号で

## 書式
```ts
import type { Chapter } from '../types';
export const chapter: Chapter = {
  id: 'S03', title: '若林博士の来訪', section: 'S03', kicker: '第2章',
  scenes: [ { id: 'S03-1', title: '…', bg: 'room7', depth: 0, source: {…}, blocks: [{ section: 'S03', from: 206, to: 240 }], summary: `…`, notes: {…}, event: 'card', cards: ['who'] }, … ],
  cards: [ … ], task: { id: 'S03', title: '理解課題：…', qs: [ … ] }, terms: [ … ], claims: [ … ],
};
```
型定義は `src/data/types.ts`．M1 の実例は `src/data/scenario_m1.ts`（場面・カード・課題の文体の手本）．
執筆後に `python3 analysis/verify_scenario.py src/data/chapters/Sxx.ts` を実行し，`OK` になるまで直す．


## 西村方針（2026-09-03 ファクトチェック後に確定）
- 原文の語はそのまま（上記規則 3）．歴史的・文化的な側面を感じながら作品を理解するのが目的で，作品から受ける意味や作者の意図に反する改変をしない
- 外部査読は **Codex（gpt-5.6-sol）のみ**．Gemini の指摘は採用しない（Gemini だけを根拠にした変更は行わない．ただし原文との一字一句の不一致・行番号誤りの訂正は，根拠が原文そのものなので出所を問わず行う）
- 刊行時（`era1935`）の注釈は参考文献付きで積極的に書く（規則 4，`.spec/REFERENCES.md`）
- 課題文（task の stmt）は要約命題を「」で示す書式で統一（原文引用にする必要はない）
