# SPEC - 技術仕様・要件定義（v0.2，2026-09-03，Gemini/Codex レビュー反映・西村承認待ち）

## 0. コンセプト
**「ドグラ・マグラ」を，遊び終えたら本当に読了したことになるゲーム．**
- 本作は「目覚め→標本室で『ドグラ・マグラ』を読む→正木の論文群→遺言書→正木との対面→時計の音で冒頭へ」という**ループ構造**と，**作中文書の入れ子**が最大の特徴．ゲームも円環を主機構にするが，「世界が実際にループした」ではなく**「同じ記憶・記述を別の前提で再読する」**機構として実装する（作中証言自体が信用できないため）．ゲートは「正解」ではなく「体験した／読んだ」ことで開く
- ホラー一辺倒にしない．**正木の論文は「遊べる論文」**（ミニゲーム＋要旨＋現代注釈）として実装し，狂気／正気の境界を問う作品の思想を体験させる
- **原文尊重**：ゲーム内の本文は青空文庫原文（ルビ付き）をそのまま用い，要約・演出テキストは「作中の言葉」と「ナビゲーター（注釈）の言葉」を UI 上で明確に区別する

## 0.5 理解目標と到達判定（Codex 指摘で追加）
「読了相当」を閲覧量ではなく説明能力で定義する．6領域：
1. **出来事**（覚醒〜結末の時系列，大正15年10月19/20日の日付問題）
2. **人物・血縁**（呉家：呉青秀→…→千世子・八代子・一郎・モヨ子，正木・若林・斎藤・黛，「私」）
3. **作中文書の主張**（外道祭文／解放治療場論／脳髄論／胎児の夢／心理遺伝論）＝「作中で提唱される疑似科学的仮説」であり事実として確定しない
4. **誰の説明か**（若林の説明／正木の説明／調査書／新聞／語り手の推測）と信頼度
5. **反証・矛盾**（矛盾台帳：正木の生死，書類の新旧，日付，語り手＝呉一郎説，父親候補，モヨ子の生死）
6. **複数解釈**（呉一郎同定は強く示唆されるが認識過程が信用できない，という二段構造．「全篇＝一瞬の夢説」と「胎児の夢論」は別物）

到達バッジは3段階：**物語版完了**（場面到達）／**論点版完了**（理解課題達成：証拠と反証を一つずつ選ぶ，誰の説明かを割り当てる）／**原文100%**（原文モードの実閲覧）．原文モードを開いただけで読了扱いにしない．
論文間の接続図（脳髄論→全身細胞の意識→反射交感→夢中遊行→胎児の夢→心理遺伝→呉一郎実験）とその飛躍を可視化する．

## 1. 採用プラットフォーム・環境（結論）
| 項目 | 採用 | 理由 |
|---|---|---|
| ハード | **ブラウザ（PC/スマホ），GitHub Pages で無料配布** | 42万字＋ルビ＋縦書き＋外字を NES/SFC に載せるのは非現実的．ブラウザなら `<ruby>` と `writing-mode: vertical-rl` が無料で使える．誰でも URL 一つで遊べる＝「手軽に体験してもらう」目的に最適 |
| レトロ要素 | **作中の「入れ子」を演出として利用**：外道祭文・新聞号外など作中文書の一部を「8bit ミニゲーム」として提示（ゲームの中のゲーム＝本の中の本） | 西村の NES 経験を活かしつつ，本編の可読性を犠牲にしない．将来 cc65 で実機版ミニゲームを切り出す拡張も可能 |
| 描画 | **二層構成**：テキスト層＝DOM（縦書き・ルビ・Noto Serif JP），演出層＝Canvas/WebGL（**PixiJS v8**，M2 以降）．**M1 は DOM＋CSS 演出のみ** | Canvas だけでは縦書きルビが困難．Phaser より軽く，DOM との併用が容易 |
| 言語/ビルド | TypeScript + Vite，依存最小 | 趣味で長期保守するため単純に |
| セーブ | localStorage（＋エクスポート JSON） | サーバ不要 |
| 画面比 | 16:9 基準（1280×720 論理解像度），縦書き時は右→左に流れる本文枠 | 本を読む体験＋演出 |

## 2. ゲームデザイン
### 2.1 ジャンル
**再読型ノベルアドベンチャー**（探索＋「遊べる論文」ミニゲーム＋証拠ボード）．
- 基本ループ：読む（原文＋演出）→ 選ぶ（対話・探索）→ 遊ぶ（作中論文のミニゲーム）→ 記憶を得る → 時計の音で冒頭へ
- 「記憶図鑑」（用語・人物・文書・場面・矛盾台帳）．各命題に**情報源（誰の説明か）**と信頼度を付す
- 常時「原文モード」で対応原文を縦書きルビで読める．3バッジ（§0.5）を別々に記録

### 2.3 周回設計（レビュー反映：Gemini「1周目30分高速ループ」と Codex「主要筋は1周で到達」が対立→Codex 案を主に採用，Gemini の入れ子演出は S04 で実現）
- **1周目で主要筋と主要論文（要旨＋ミニゲーム）に到達可能**（物語版完了）．全文再読を強制しない
- 結末の時計音でタイトルへ戻ると**再読モード**：任意地点へ跳べる索引，証拠配置の比較，論文全文エリア，隠し展示．最短20〜30分で「別の前提で再読」できる
- 常時：**原文モード**（どの場面でも対応原文を縦書きで開ける）．読んだ範囲が原文100%バッジに反映

### 2.4 「怖さ」以外の楽しさ（必須要素チェックリスト）
- [ ] 精神医学考察：作中主張（脳髄論・心理遺伝・夢中遊行）と現代からの注釈を**別枠**で提示．**三時点を分離**（大正15年の作中時間／昭和10年の刊行時／現代医学）．差別語は「初出時に短い注意→辞典に詳説→設定で反復抑制」の三層．「当時は普通」で免責せず，誰が誰に使う語かを示す．**公開前に当事者または精神医療史研究者の外部レビューを必須条件**とする
- [ ] 論文的記述：学位論文の体裁（表題・章・図版）を UI で再現し，要旨と全文を切替可能
- [ ] 執筆手法：入れ子構造の可視化．固定階層のパンくずではなく**「現在どの資料を，誰の説明で信じているか」**を表示．画面周縁の「本の余白の厚み」・ページ音の深さで階層を体感させる
- [ ] 文章構造：ブウウン→冒頭回帰の円環，巻頭歌の再出，語り手の信頼できなさを機構化
- [ ] 語彙：阿呆陀羅経・チョンガレ・夢中遊行など用語辞典

## 3. グラフィック方針（レビュー反映）
- **現実層（ノベル本編）：AI 生成のセピア調・昭和初期写実絵画／古写真調**．3段構え：A 参照シート（正面・側面・全身・色見本）付き生成で一貫性確保 → B CSS 古写真フィルタ（セピア・粒状・紙質感）で顔の不一致を吸収 → C 人物はシルエット＋象徴パーツ1色（モヨ子の赤，正木の鼻眼鏡）
- **作中文書層**：紙面・版画・活版を基本（論文＝学位論文の体裁，号外＝活版，絵巻物＝古びた絹本＋墨で抽象度を上げる）
- **ドット絵は明確に遊戯化した部分（ミニゲーム）だけに限定**（ドット絵は入れ子そのものではなく現代のゲーム側が加えた翻案，という Codex の整理を採用）
- **素材は最小から**：M1 は七号室背景1・柱時計1・原稿表紙1．M2 は1場面1基調画＋重要物品．表情差分・差分背景は M3 で必要性を見て追加（当初見積の背景40/差分80・12名×表情は上限目安）
- 登場人物：私・若林鏡太郎・正木敬之・呉一郎・呉モヨ子（＝六号室の少女，同一人物）・呉千世子・呉八代子・呉青秀・斎藤寿八・黛芬子・看護婦
- 生成ツール：量産＝**Nano Banana 2**，主要人物・キーアート＝**Nano Banana Pro**（Gemini 2.5 Flash Image はレガシー扱い，要現行確認 https://ai.google.dev/gemini-api/docs/image-generation ）．生成物ごとに人物ID・モデル・プロンプト・参照画像・シード相当情報を **assets/LEDGER.csv** に記録．SDXL 系は量産で問題が出てから．いらすとやは開発用プレースホルダーに限定
