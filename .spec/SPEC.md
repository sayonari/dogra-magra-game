# SPEC - 技術仕様・要件定義（v0.1 ドラフト，2026-09-03，AIレビュー前）

## 0. コンセプト
**「ドグラ・マグラ」を，遊び終えたら本当に読了したことになるゲーム．**
- 本作は「目覚め→標本室で『ドグラ・マグラ』を読む→正木の論文群→遺言書→正木との対面→時計の音で冒頭へ」という**ループ構造**と，**作中文書の入れ子**が最大の特徴．ゲームもループを主機構にする：1周目に理解できない語（脳髄論・心理遺伝・夢中遊行・絵巻物）が「記憶の断片」として持ち越され，2周目以降に新しい選択肢・場面が開く（Outer Wilds／シュタインズ・ゲート型の「知識ゲート」）
- ホラー一辺倒にしない．**正木の論文は「遊べる論文」**（ミニゲーム＋要旨＋現代注釈）として実装し，狂気／正気の境界を問う作品の思想を体験させる
- **原文尊重**：ゲーム内の本文は青空文庫原文（ルビ付き）をそのまま用い，要約・演出テキストは「作中の言葉」と「ナビゲーター（注釈）の言葉」を UI 上で明確に区別する

## 1. 採用プラットフォーム・環境（結論）
| 項目 | 採用 | 理由 |
|---|---|---|
| ハード | **ブラウザ（PC/スマホ），GitHub Pages で無料配布** | 42万字＋ルビ＋縦書き＋外字を NES/SFC に載せるのは非現実的．ブラウザなら `<ruby>` と `writing-mode: vertical-rl` が無料で使える．誰でも URL 一つで遊べる＝「手軽に体験してもらう」目的に最適 |
| レトロ要素 | **作中の「入れ子」を演出として利用**：外道祭文・新聞号外など作中文書の一部を「8bit ミニゲーム」として提示（ゲームの中のゲーム＝本の中の本） | 西村の NES 経験を活かしつつ，本編の可読性を犠牲にしない．将来 cc65 で実機版ミニゲームを切り出す拡張も可能 |
| 描画 | **二層構成**：テキスト層＝DOM（縦書き・ルビ・Noto Serif JP），演出層＝Canvas/WebGL（**PixiJS v8**） | Canvas だけでは縦書きルビが困難．Phaser より軽く，DOM との併用が容易 |
| 言語/ビルド | TypeScript + Vite，依存最小 | 趣味で長期保守するため単純に |
| セーブ | localStorage（＋エクスポート JSON） | サーバ不要 |
| 画面比 | 16:9 基準（1280×720 論理解像度），縦書き時は右→左に流れる本文枠 | 本を読む体験＋演出 |

## 2. ゲームデザイン
### 2.1 ジャンル
**記憶持ち越し型ループ・ノベルアドベンチャー**（探索＋論文ミニゲーム）．
- 基本ループ：読む（原文＋演出）→ 選ぶ（対話・探索）→ 遊ぶ（作中論文のミニゲーム）→ 記憶を得る → 時計の音で冒頭へ
- 「記憶図鑑」（用語・人物・文書・場面）が周回で埋まる．全項目解放＝**読了証**（原文読了率 100% を可視化）

### 2.2 章立て（`analysis/sections.json` の13区分を基に，S11 は要サブ分割）
| 章 | 原文区分 | ゲーム内の形式 | 学べること |
|---|---|---|---|
| 序 | S01 巻頭歌 | タイトル演出（胎児よ…） | 主題の提示 |
| 第1章 覚醒 | S02 | ノベル＋「七号室」探索（一人称） | 記憶喪失・語りの不確かさ |
| 第2章 若林 | S03 | 対話ADV（選択肢で若林の説明を引き出す） | 事件の外形・解放治療場 |
| 第3章 標本室 | S04 | ポイント＆クリック探索．展示物を調べると作中文書が「入手」される．原稿「ドグラ・マグラ」を見つけると巻頭歌が再出＝入れ子の気づき | 執筆構造（本の中の本） |
| 第4章 外道祭文 | S05 | **8bit風リズム／読経ゲーム**（チョンガレ節・数え唄）．歌詞は原文 | 精神病院・当時の医学への批判 |
| 第5章 解放治療場論 | S06 | 講演を聴く（短編ノベル）＋「誰が狂人か」判定できないクイズ | 正常／異常の相対性 |
| 第6章 脳髄論 | S07 | **「電話交換局」パズル**：細胞からの信号を交換手（脳髄）が中継するだけ，という説を操作で体得．論文要旨カード付き | 脳髄＝交換局説 |
| 第7章 胎児の夢 | S08 | **横スクロール「十月十日」**：単細胞→魚→両生類→哺乳類→人へ進化しつつ先祖の記憶（罪業）が夢として現れる | 胎児の夢＝系統発生の反復・心理遺伝の芽 |
| 第8章 遺言書 | S09 | ノベル（長文）＋**呉家系図・絵巻物復元パズル**（呉青秀→呉一郎の心理遺伝トリガーを組み立てる） | 心理遺伝論・呉家の由来 |
| 第9章 呉一郎事件 | S10 | 事件記録の再構成（時系列並べ替え・証言照合） | 千世子殺害・モヨ子絞殺・再現実験 |
| 第10章 正木との対面 | S11（サブ分割） | 長編対話ADV＋解放治療場探索．**「私は誰か」証拠ボード**：若林説／正木説を並べ，決着がつかないことを体験 | 語り手の同一性・探偵小説の脱構築 |
| 第11章 号外 | S12 | 新聞紙面 UI（8bit/活版風）で読む | 事件の外部からの見え方 |
| 終章 | S13 | 結末→時計の音→**タイトルへ戻る**（周回カウント＋記憶図鑑更新） | ループ構造 |

### 2.3 周回設計（案）
- 1周目：本筋のみ．論文は要旨版．正体論争は途中で「ブウウン」で強制ループ
- 2周目：記憶図鑑の鍵で標本室・治療場の隠し展示，論文の全文モード，若林／正木への追加質問が開く
- 3周目以降：「私＝呉一郎」「私＝別人」「全てが胎児の夢」の各解釈ルートを選べる（結論を押しつけず，解釈の複数性を体験させる）
- 常時：**原文モード**（どの場面でも右上の本アイコンから対応原文を縦書きで開ける）．読んだ範囲がゲージに反映

### 2.4 「怖さ」以外の楽しさ（必須要素チェックリスト）
- [ ] 精神医学考察：作中主張（脳髄論・心理遺伝・夢中遊行）と，現代からの注釈（当時の精神病院法・「精神分裂病」概念の時代性・現代の理解）を**別枠**で提示
- [ ] 論文的記述：学位論文の体裁（表題・章・図版）を UI で再現し，要旨と全文を切替可能
- [ ] 執筆手法：入れ子構造の可視化（「今読んでいる文書の階層」をパンくずで表示）
- [ ] 文章構造：ブウウン→冒頭回帰の円環，巻頭歌の再出，語り手の信頼できなさを機構化
- [ ] 語彙：阿呆陀羅経・チョンガレ・夢中遊行など用語辞典

## 3. グラフィック方針
- **本編（ノベル層）：AI 生成の「昭和初期・写実絵画調」**（銅版画／水彩／古写真のトーン，セピア＋差し色1色）．統一スタイルガイド（プロンプト共通接頭辞＋参照画像）でキャラ一貫性を確保
- **入れ子層（作中文書のミニゲーム）：ドット絵（16bit 風）**．「本の中の本」を絵柄の差で表現
- 必要素材（初期見積）
  - 背景：七号室（朝/昼/夜/幻覚）・廊下と柱時計・六号室・標本室（全景＋展示棚×6）・解放治療場（庭/病棟）・若林の部屋・正木の教授室・呉家（唐代/現代）・新聞紙面 … 約 **40 枚**（段階差分含め 80 バリエーション）
  - 人物：私・若林・正木・呉一郎・モヨ子・千世子・八代子・呉青秀・斎藤・黛芬子・六号室の少女・看護婦 … **12 名 × 表情 4〜6**
  - 物品：脳髄模型・胎児標本・絵巻物（場面 6 枚）・懐中時計・柱時計・遺言書・論文表紙・阿呆陀羅経の木魚… 約 **30 点**
- 生成ツール割当：一次＝**Nano Banana（Gemini 2.5 Flash Image）／Nano Banana Pro**（参照画像による一貫性が強い），二次＝Midjourney／SDXL 系（必要なら），ドット絵＝Nano Banana で「pixel art 16-bit」指定＋Aseprite で手修正，最終手段＝いらすとや

## 4. 音楽・効果音方針
- BGM：**Suno**（西村は利用経験あり）で章別 12〜15 曲．プロンプト方針：「昭和初期の蓄音機」「大正ジャズ」「読経・チョンガレ節」「脳髄ドローン」「胎児の夢＝羊水アンビエント」．ミニゲームは「8-bit chiptune」指定
- 代替／補完：フリー音源（DOVA-SYNDROME，魔王魂，甘茶の音楽工房）＋ Furnace tracker で自作 chiptune（NES 音源を本物にしたい場合）
- SFX：効果音ラボ・freesound（CC0）＋ **Web Audio で合成**（柱時計「ブウウ——ンンン」は作品の署名音なので専用に設計：低周波ベル＋残響＋ピッチ揺れ）
- 音声（任意）：正木の外道祭文を **VOICEVOX／Style-Bert-VITS2** で読経風に合成（西村の専門領域）
- ライセンス：Suno は有料プランで商用可（配布は無料でも規約確認），フリー素材はクレジット表記を `CREDITS.md` に集約

## 6. データ設計
- `analysis/text_clean.txt`：ルビ・注記除去版（解析用）
- `analysis/sections.json`：13区分（行範囲・字数）
- `src/data/script/*.json`：場面スクリプト（scene id，原文行範囲，話者，背景/立ち絵指定，選択肢，取得する記憶 id）
- `src/data/text/*.json`：原文をルビ HTML 化した段落配列（青空文庫記法→`<ruby>`変換スクリプトで自動生成，**手編集禁止**）
- `src/data/glossary.json`：用語辞典（作中の定義・原文引用行・現代注釈・出典）

## 8. 非機能要件
- PC/スマホ両対応，オフライン動作（PWA は任意），初回ロード < 10MB（画像は WebP，遅延読込）
- アクセシビリティ：文字サイズ変更・横書き切替・読み上げ（任意）
- 出典表示：タイトル画面と設定に青空文庫の出典・底本を明記
