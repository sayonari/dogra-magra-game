## 技術的な知見
- 青空文庫記法：ルビ `｜漢字《かな》`，注記 `［＃…］`．HTML `<ruby>` に機械変換できる → ブラウザなら原文ルビ表示が無料で手に入る
- 縦書きは CSS `writing-mode: vertical-rl` で可能．Canvas 単体では困難 → 「テキスト層＝DOM，絵・演出層＝Canvas/WebGL」の二層構成が合理的
- 西村は cc65 による NES 開発経験あり（private_work/neswork，FamilyBird2）．ただし 42万字の日本語（漢字）をNES/SFC に載せるのはフォントROM・容量・ルビの点で非現実的

## 決定事項と理由
- （SPEC.md 確定後に追記）
- **ブラウザ採用**（NES/SFC 却下）：42万字＋ルビ＋外字の可読性，`<ruby>`・縦書きが無料，URL 一つで配布．西村の cc65 経験は将来の実機版ミニゲーム切り出しに温存
- **「読了」＝説明能力で定義**（Codex）：理解目標6領域・3段階バッジ．閲覧量で読了扱いしない
- **周回設計は Codex 案**（主要筋は1周で到達，再読モードは任意）．Gemini の「1周目30分強制ループ」は「遊び終えたら読了」の宣言と食い違うため不採用（折衷の余地は序盤演出として残す）
- **絵柄二層**：現実層セピア写実＋古写真フィルタ／文書層は紙面・版画・活版／ドット絵はミニゲームのみ（ドット絵は現代側の翻案であり入れ子そのものではない）
- **作品理解の訂正（Codex）**：モヨ子＝六号室の少女（同一人物）／モヨ子絞殺は未遂・仮死／千世子殺害は呉一郎の犯行と確定しない／「全篇＝一瞬の夢説」と「胎児の夢論」は別／呉一郎同定は強く示唆されるが認識過程が崩壊する二段構造
- **M1 は理解検証用縦切り**（縦書きエンジンの完成度ではなく「作中の説を理解しつつ真実と断定しない状態」を短いプレイで作れるかを検証）
