<p><strong>総評：</strong>方向性は非常に良く，とくに「作中論文を遊びに変換する」「原文と注釈を分離する」「入れ子をUI化する」という発想は作品に適合しています．一方，現状は<strong>原作の理解より，ループゲームとしての気持ちよさと素材量が先行</strong>しています．最大の課題は，「何を理解できれば読了相当なのか」が定義されていないことです．</p>

<h2>1．計画の致命的な問題点（優先順）</h2>

<ul>
<li><strong>理解目標と評価方法がない．</strong>「原文読了率100％」「記憶図鑑完成」は閲覧量の指標であり，作品理解の証明ではありません．人物関係，作中文書の主張，証言間の矛盾，結末の未確定性を説明できるか，という到達基準が必要です．</li>

<li><strong>「円環構造」を客観的な時間ループとして固定しすぎている．</strong>冒頭と末尾の時計音，前日の出来事の反復，一瞬の夢という説明はループ解釈を強く支えますが，作中証言自体が信用できません．毎周タイトルへ戻すなら，「世界が実際にループした」ではなく「同じ記憶・記述を別の前提で再読する」機構にすべきです．</li>

<li><strong>42万字を読ませる計画と，手軽なゲームという目的が両立していない．</strong>1周目が要旨だけなのに「遊び終えたら読了」とすると，宣言と実態が食い違います．「物語体験完了」「主要論点理解」「原文読了」を別の達成段階に分けるべきです．</li>

<li><strong>ミニゲームが論文の比喩を単純化する危険がある．</strong>脳髄論は単なる信号配線説ではなく，全身細胞の意識，反射交感，記憶，夢中遊行，心理遺伝へ連結します．交換局パズルだけでは核心の半分しか伝わりません．</li>

<li><strong>M2まで教育的ゲーム性を検証できない．</strong>現行M1は覚醒章の表示試作だけなので，「遊べば理解できる」という最大の技術・設計リスクを検証しません．</li>

<li><strong>素材規模が過大．</strong>背景80差分，12名×4～6表情，物品30点，BGM15曲を先に想定すると，一貫性管理と差し替え作業が本編設計を圧迫します．まず1場面1基調画＋重要物品で十分です．</li>

<li><strong>仕様と構造データが同期していない．</strong>SPECはS11を「要サブ分割」としていますが，<code>sections.json</code>には既に11分割があります．単一の正本を決める必要があります．</li>
</ul>

<h2>2．「遊べば本当に内容が理解できる」ために不足している要素</h2>

<ul>
<li><strong>学習到達目標：</strong>最低でも「出来事」「人物・血縁」「作中文書の主張」「誰の説明か」「反証・矛盾」「複数解釈」の6領域を定義する．</li>

<li><strong>情報源の表示：</strong>パンくずだけでなく，各命題に「若林の説明」「正木の説明」「調査書」「新聞」「語り手の推測」を付ける．本作では文書階層以上に，発話者と信頼度が重要です．</li>

<li><strong>主張と事実の分離：</strong>脳髄論・心理遺伝論を「作中で提唱される疑似科学的仮説」と明示し，ゲームの世界設定上の真理として確定しない．</li>

<li><strong>矛盾台帳：</strong>日付，正木の生死，書類の新旧，語り手＝呉一郎説，父親候補，モヨ子の生死などを，解決済みではなく「両立しない証拠」として残す．</li>

<li><strong>理解確認：</strong>正解当てクイズではなく，「この結論を支持する証拠と反証を一つずつ選ぶ」「誰の説明だったかを割り当てる」課題にする．</li>

<li><strong>論文間の接続図：</strong>脳髄論→全身細胞の意識→夢中遊行→胎児の夢→心理遺伝→呉一郎実験，という論理鎖と，その飛躍を可視化する．</li>

<li><strong>倫理・歴史レイヤー：</strong>1920年代の制度，1935年の作品，現代医学の三時点を分離する．差別語の説明だけでなく，患者を研究材料化する正木・若林の暴力も主題化する．</li>

<li><strong>読了の三段階化：</strong>「物語版完了」「論点版完了」「原文100％」を別バッジにする．原文モードを開いただけで読了扱いにしない．</li>
</ul>

<h2>3．「9．未決事項」への推奨</h2>

<ol>
<li><strong>絵柄：</strong>二層案を採用．ただし「本編＝写実，文書＝すべてドット絵」という機械的区分は避け，現実層はセピア調，作中文書は紙面・版画・活版を基本にし，ドット絵は明確な遊戯化部分だけに限定する．ドット絵は入れ子そのものではなく，現代のゲーム側が加えた翻案だからです．</li>

<li><strong>難易度：</strong>全ミニゲームをスキップ可能にする．ただし「スキップ＝内容も消える」にせず，自動実演＋要旨＋論理図を表示する．高難度報酬は設定資料や演出差分に留め，作品理解を操作技量で遮断しない．</li>

<li><strong>S11：</strong><code>sections.json</code>の11分割を出発点に，5つのプレイ単位へ再編する．「正木出現と日付反転」「解放治療場と実験倫理」「絵巻・呉家・女性たち」「私の正体とW／M」「白紙・千世子の書込・惨劇」．各単位の終わりに証拠ボードを更新し，正木の長広舌を途中選択で細切れにしない．</li>

<li><strong>精神医学注釈：</strong>原文は改変せず，初出時に短い注意，辞典に詳説，設定で反復表示を抑制する三層方式を推奨．「当時は普通だった」で免責せず，歴史的用法，現在は不適切な理由，作中で誰が誰に使う語かを示す．当事者または精神医療史研究者による外部レビューを公開前の必須条件にする．</li>

<li><strong>周回：</strong>主要筋と主要論文は1周で到達可能にする．2周目は必須ではなく「再読モード」とし，最短20～30分で異なる証拠配置を比較できるようにする．全文再読を強制せず，任意地点へ跳べる索引を解禁する．</li>
</ol>

<h2>4．画像・音楽・効果音のAI割当と代替案</h2>

<ul>
<li><strong>画像：</strong>Nano Banana系を一次担当にする判断は妥当です．ただしSPEC記載のGemini 2.5 Flash Imageは現在レガシー扱いなので，量産はNano Banana 2，主要人物・キーアートはPro，という更新が合理的です．公式資料も複数参照画像と人物一貫性を明示しています（<a href="https://ai.google.dev/gemini-api/docs/image-generation">Google公式</a>）．</li>

<li><strong>人物一貫性：</strong>プロンプト共通接頭辞だけでは不足です．先に正面・側面・全身・色見本を含むキャラクターシートを確定し，生成物ごとに人物ID，モデル，プロンプト，参照画像，シード相当情報を記録するべきです．</li>

<li><strong>代替：</strong>SDXL系は一貫性をローカルで固定したい場合に有効ですが，環境構築と学習コストが高いため，量産段階で問題が出てから導入すれば十分です．「いらすとや」は画調と恐怖・官能・歴史性が衝突するため，最終代替ではなく開発用プレースホルダーに限定するのが安全です．</li>

<li><strong>BGM：</strong>Sunoは試作と着想には適しますが，12～15曲を先に生成せず，無音，時計音，環境音を中心に3曲程度で縦切り検証するべきです．有料プラン生成物には商用利用条件がありますが，生成時点の契約・ダウンロード条件を素材台帳に保存してください（<a href="https://suno.com/terms-september-2026">Suno利用規約</a>）．</li>

<li><strong>外道祭文：</strong>一般的な「読経風」にすると阿呆陀羅経・チョンガレの芸能性を潰します．AI音声の前に，節回しとリズムの資料調査を行い，仮実装は字幕＋木魚・鉦のリズムでよいです．</li>

<li><strong>SFX：</strong>Web Audioによる時計音の専用設計は強く推奨します．ただし低周波を強くしすぎず，音量制限，ミュート，振動・画面点滅の無効化を必須にする．時計音はBGM以上に作品構造を担うため，最優先音素材です．</li>
</ul>

<h2>5．作品理解上の誤り・修正点</h2>

<ul>
<li><strong>モヨ子と六号室の少女は別キャラクターではありません．</strong>素材一覧の二重計上を修正する必要があります．</li>

<li><strong>S10の「モヨ子絞殺」は未遂・仮死・後の呼び声を含めて扱うべきです．</strong><code>sections.json</code>は「未遂」としていますが，SPECでは落ちています．また，千世子殺害も呉一郎の犯行と確定していません．</li>

<li><strong>「私＝呉一郎」「私＝別人」を完全に対等な選択エンディングにしない方がよいです．</strong>終盤は「正木一郎」という書込，千世子＝母，正木＝父，モヨ子の「一郎兄さん」など，呉一郎同定を強く補強します．一方で書類や知覚そのものが崩壊するため，確定できない，という二段構造です．</li>

<li><strong>「全てが胎児の夢」は表現が不正確です．</strong>作中には，全体が時計音を聞いた精神病者の一瞬の夢かもしれないという説明がありますが，胎児が全篇を夢見ていると確定するわけではありません．「全篇＝一瞬の夢説」と「胎児の夢論」を分けるべきです．</li>

<li><strong>胎児の夢は単なる進化ステージではありません．</strong>個体発生が系統発生を反復するという発想に加え，祖先の経験・恐怖・罪業が細胞に刻まれるという心理遺伝論への橋渡しです．横スクロール化するなら，進化するほど進歩するゲームではなく，記憶が堆積して逃れにくくなる設計が適します．</li>

<li><strong>脳髄論は「脳が中継するだけ」で終わりません．</strong>思考・感覚・記憶を全身細胞へ分散し，脳髄の反射交感の破綻から夢・精神異常・心理遺伝を説明しようとする体系です．</li>

<li><strong>入れ子は安定した一方向の階層ではありません．</strong>作品内の原稿『ドグラ・マグラ』が外側の作品を予告・反復し，文書が現在の語りを侵食します．パンくずは固定階層ではなく，「現在どの資料を，誰の説明で信じているか」を表示すべきです．</li>

<li><strong>「精神分裂病概念の時代性」は用語確認が必要です．</strong>大正十五年の作中時間，昭和十年の刊行時，後世の診断語を混同せず，作品本文で使用される語と現代注釈の語を区別してください．</li>
</ul>

<h2>6．最小構成で最初に作るべきM1</h2>

<ul>
<li><strong>20～30分の「理解検証用縦切り」に変更する．</strong>S01巻頭歌→S02覚醒の抜粋→S04で原稿発見→S07脳髄論の短い一節→時計音による再読，までを収録する．これで本文表示だけでなく，入れ子，論文，反復を一度に検証できます．</li>

<li><strong>実装はDOM中心にする．</strong>縦・横書き切替，ルビ，文字サイズ，原文／要旨／現代注釈の三表示，既読位置保存を作る．M1ではPixiJSを必須にせず，CSS演出と仮画像1～2枚で十分です．</li>

<li><strong>証拠カードを3枚だけ実装する．</strong>「私は誰か」「時計音」「原稿内の巻頭歌」を取得し，事実・発言者・推測を区別して表示する．記憶図鑑全体より先に，情報の信頼度モデルを検証します．</li>

<li><strong>脳髄論ミニゲームを一つだけ作る．</strong>交換局で信号をつなぐ前半と，接続が乱れて複数の解釈が発生する後半を設ける．終了後に「作中説」「現代医学」「物語上の役割」の三枚を表示する．</li>

<li><strong>読了判定を三種類に分ける．</strong>場面到達，原文閲覧，理解課題達成を別々に記録する．</li>

<li><strong>M1の合格条件を利用者の説明能力に置く．</strong>初見者5名程度がプレイ後に「脳髄論は作者や現代医学の事実ではない」「原稿が物語を入れ子にする」「語り手の正体は示唆されるが認識過程は信用できない」の3点を自分の言葉で説明できれば次へ進む．</li>

<li><strong>素材制作は最小限にする．</strong>七号室背景1枚，柱時計1点，原稿表紙1点，環境音1本，時計音1本，BGM最大1曲．スタイルガイドはこの6素材を揃えられることをもって確定する．</li>
</ul>
